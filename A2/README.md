## LSTM-Based Language Model for Text Generation

This project implements a complete **end-to-end language modeling pipeline** using an **LSTM (Long Short-Term Memory) neural network**.  
The trained model is capable of generating English text in the style of classic literature and is deployed via a **Dash web application** for interactive text generation.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------



### Project Objectives

- Build a **word-level LSTM language model**
- Train on a corpus of **classic English literature**
- Evaluate using **training & validation loss / perplexity**
- Generate text using **temperature + top-k sampling**
- Deploy the model using a **Dash web application**

### Dataset Description

The training corpus was constructed using ten classic English novels sourced from Project Gutenberg. Each book was downloaded programmatically using its unique Gutenberg identifier. Official Project Gutenberg START and END markers were used to remove headers, footers, and licensing text, ensuring that only the narrative content was retained.

The selected works include novels by Lewis Carroll, Jane Austen, Mary Shelley, Charles Dickens, Herman Melville, Oscar Wilde, Bram Stoker, and Arthur Conan Doyle. All texts are in the public domain.

After extraction, the corpus was lightly normalized to standardize whitespace and line breaks while preserving paragraph structure. The resulting dataset provides a diverse yet stylistically coherent body of literary English suitable for training a word-level LSTM language model.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------
The texts are:
1. Downloaded programmatically
2. Cleaned to remove front matter (title pages, tables of contents)
3. Normalized (quotes, punctuation, whitespace)

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### 🧹 Text Preprocessing

Key preprocessing steps:

- Lowercasing
- Unicode normalization (quotes, dashes)
- Removal of Gutenberg metadata
- Word-level tokenization using regular expressions
- Vocabulary creation with `<pad>` and `<unk>` tokens

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### 🧠 Model Architecture

The language model is an **LSTM-based neural network** with the following structure:

- **Embedding Layer**
- **Multi-layer LSTM**
- **Linear Output Layer (Softmax over vocabulary)**

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### Training Hyperparameters (final model)

```text
Embedding Dimension : 256
Hidden Dimension    : 1024
LSTM Layers         : 3
Dropout             : 0.3
Sequence Length     : 50
Optimizer           : Adam
Loss Function       : Cross-Entropy Loss
```
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

🏋️ Training

Data split: 90% training / 10% validation

Training performed using mini-batches generated by a custom get_batch function

Gradient clipping used to stabilize training

Loss and perplexity tracked over time

## How to Use This Application

Follow the steps below to run the LSTM Text Generation web application locally.

1. Clone the repository
   git clone https://github.com/lamanabin2046/Natural-Languages-Processing.git

2. Navigate to the project directory
   cd Natural-Languages-Processing/A2
   
4. (Optional) Create and activate a virtual environment

   python -m venv venv  
   source venv/bin/activate        (Linux / macOS)  
   venv\Scripts\activate           (Windows)
5. Install required dependencies
   pip install -r requirements.txt
6. Navigate to the code directory
   cd code
7. Run the Dash application
   python app.py
8. Open the application in a web browser
   http://127.0.0.1:8050/
